# Zoryvn Finance Dashboard ✦

A highly premium, deeply interactive, and visually stunning personal finance tracking application. Engineered natively with **React** and **Vite**, Zoryvn abandons generic layouts for a bespoke, glassmorphic `#030712` dark-mode aesthetic. 

The dashboard isn't just a ledger—it's a predictive analytics engine powered by mathematically dense derivations, robust edge-casing, and a world-class micro-animation physics system built to react to every user interaction natively.

---

## ✨ Exhaustive Feature Overview

### 🧠 Deep Analytics & Intelligence Engine (derive.js)
- **Financial Health Scoring Engine**: Computes a dynamic 100-point grade recursively weighing your active Savings Ratio (40%), Standard Deviation structural consistency (30%), and individual Category concentration limits (30%).
- **Actionable AI-like Insights**: Flags distinct spending vulnerabilities mapping threshold suggestions natively—such as predicting duplicate active subscriptions, identifying 3-month category outflow spikes, targeting sub-20% savings gaps, and suggesting 20% drops if food dominates your outbound cash.
- **Suspicious Pattern Mapping**: Built-in array aggregators detect anomalous bursts grouped natively by aggressive 48-hour arrays, unusual single expenditures, and localized 3-hour time-of-day behavioral clusters (tracked dynamically with timestamps).
- **"No-Spend" Streak Tracking**: Tracks consecutive absolute daily windows charting current and maximum historical 0-expense runs naturally parsing chronological bounds.
- **Algorithmic Personality Tagging**: Assigns dynamic spending personas (e.g. *Night Owl Shopper*, *Weekend Warrior*, *Foodie*) parsing your temporal and categorical transaction footprints.

### 🎨 World-Class Micro-Interaction Physics (Framer Motion)
- **Universal Reduced Motion Integrity**: Every single animation variable across the app guarantees 100% accessibility compliance. If `prefers-reduced-motion` is active, scaling springs, translations, and rotation matrices map to instant pure 0-millisecond opacity fades globally.
- **Native Easing & Spring Physics**: Explicit tracking mechanics enforcing CSS defaults into dynamic Framer hooks (`stiffness: 400`/`damping: 17` native mousedown springs mapped alongside exactly bounded `200ms ease-out` hover matrices eliminating standard `transition: all` lag).
- **Scale Bounding & Stagger Loops**: Render arrays initiate explicitly staggered lists (capped logically indexing 8 elements preventing load lag), throwing cascading teal origin boundaries masking standard `<div/>` layouts seamlessly.
- **Complex UI Modals**: Add-Transaction modaling utilizes pure localized `AnimatePresence` backdrops forcing unmount drop animations `(y:60->0)` smoothly tracing DOM exits securely.
- **1200ms Easing Rings**: The Financial Health Score SVG renders complex stroke circumferences mathematically triggering pure `<motion.circle>` sweeps paired precisely with native integer layouts scaling dynamically from zero on DOM mapping via `useMotionValue`.
- **Intelligent Route Routing**: Swapping active pages dynamically traces an entire `AnimatePresence (wait)` root map yielding uniform `y:12->0` sliding delays maintaining state memory.

### 🛡️ Robust State & Absolute Edge Casing
- **Absolute 0-Transaction Overrides**: Instead of rendering generic UI structures mapping null charts, a specialized `EmptyGlobalState.jsx` captures 100% empty `Zustand` arrays replacing your primary viewport immediately guiding users to inject basic timeline inputs.
- **"100% Savings" Pure-Income Checks**: Intelligently overrides Insights tables directly preventing division faults mapping a dedicated SVG notification screen whenever localized users only cast Income without touching absolute Outbound channels.
- **Secure Modal Input Validations**: Add-Transaction UI forces exact mapping behaviors, explicitly locking standard browser limits masking generic strings across strict input requirements preventing array pollution.
- **Live Local Storage Persistence**: Handled locally via `localStorage` arrays mounted onto the `Zustand` global cache parsing live DOM boundaries tracking exact UI pings shifting visually onto the persistent dashboard footer (`StorageStatusBadge.jsx`).

## 🚀 Technical Stack

- **Core Framework**: [React 18](https://react.dev/) bundled via [Vite](https://vitejs.dev/)
- **Aesthetic Boundaries**: [Tailwind CSS v4](https://tailwindcss.com/) (Tailored deep `#030712` slate palettes & Custom glassmorphic gradients)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Animation Physics**: [Framer Motion](https://www.framer.com/motion/)
- **Data Plotting**: [Recharts](https://recharts.org/)
- **Vector Iconography**: [Lucide React](https://lucide.dev/)
- **Master Typography**: [Fontsource Sora](https://fontsource.org/fonts/sora)

## 📁 System Architecture

```text
src/
├── components/          # Scalable interactive UI mounts (ActionableSuggestions, StreakCards, Recharts, Modals)
├── data/                # Mock array schemas mapping historical transaction boundaries natively testing pattern bounds
├── pages/               # Primary layout instances (Overview, Transactions, Insights)
├── store/               # Zustand hooks orchestrating persistence loops, arrays, and standard active filter layers 
├── utils/               # Intensive analytical derivation formulas (`derive.js`) returning distinct arrays
├── App.jsx              # Root layout parsing explicit Framer navigation paths
└── index.css            # Tailwind configurations masking default structural rendering flows (`::-webkit-scrollbar` hooks)
```

## 🛠️ Local Environment Boot

1. **Pull Dependencies:**
   ```bash
   npm install
   ```

2. **Launch the Environment Interface:**
   ```bash
   npm run dev
   ```

3. Fire open the port in your browser. All interactions scale completely bound to your browser's persistent `localStorage`. Add new records out of the ledger dashboard via the tracking button to instantly see global metrics mathematically offset themselves across all charts, widgets, and suggestions natively!
